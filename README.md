# Max & Minou 🌿

Vegane Rezepte für zwei — jede:r kocht seinen Teil, gemeinsam geht's an den Tisch.

## Konzept

Kein Danebenstehen mehr. Jedes Rezept ist in zwei parallele Teile aufgeteilt:
- **Max** kocht einen Teil
- **Minou** kocht den anderen
- Am Ende richten beide gemeinsam an

Jede Person öffnet das Rezept auf ihrem Gerät, wählt ihre Rolle — und sieht nur ihre eigenen Schritte.

## Features

- Rollenauswahl (Max / Minou) pro Gerät
- Schritte einzeln abhakbar (Tippen auf die Nummer)
- Gemeinsamer Anricht-Block am Ende
- Reines HTML/CSS/JS — kein Framework, kein Build-Schritt

## Rezepte

| Rezept | Zeit |
|--------|------|
| Knuspriger Kartoffelsalat mit Spargel & Honig-Senf-Dressing | 50 Min. |
| Cremige Pasta Primavera mit Zitronen-Cashew-Sauce | 30 Min. |
| Buddha Bowl mit Süßkartoffel & Tahini-Dressing | 40 Min. |

## Struktur

```
index.html              ← Startseite mit Rezeptübersicht
rezepte/
  kartoffelsalat-spargel.html
  pasta-primavera.html
  buddha-bowl.html
```
